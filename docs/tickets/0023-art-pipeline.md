# 0023 — Procedural art pipeline & style guide

- **Status:** ready
- **Milestone:** M9 — Visual Overhaul
- **Depends on:** 0015

## Goal
Create a reproducible way to produce richer pixel art (no external art tools), a written style guide, and the first assets (resource icons) through it.

## Context
Owner feedback (2026-10-26): textures must be more interesting, structures must be distinguishable, overall graphics are too simple. There is no image editor or Python imaging in this environment, so art is generated by a Godot script using the `Image` API, and the PNGs are committed.

## Scope
- `tools/art/generate_art.gd` (`extends SceneTree`), run with:
  `/Applications/Godot.app/Contents/MacOS/Godot --headless --path . -s tools/art/generate_art.gd`
  then `--headless --path . --import` to import new files. Writes PNGs under `assets/art/`.
- `tools/art/pixel_canvas.gd`: helpers on top of `Image` — rect, filled/outlined ellipse, line, polygon fill, dithered gradient, value noise texture fill, 1px dark outline pass around non-transparent pixels, drop shadow, seeded RNG for deterministic variation.
- `tools/art/palette.gd`: a curated ~32-color palette (earthy greens, browns, wood, thatch, slate, stone greys, roof reds/blues, water, snow, autumn oranges). All generated art uses it.
- `docs/art-style.md`: view (top-down with slight 3/4 front face so buildings show walls and roofs), 32 px tiles, light from top-left, 1px dark outline on objects, soft shadow to bottom-right, readability rules (each building: unique silhouette + unique roof color + a telling prop; must be identifiable at default zoom).
- First assets: 16x16 icons for every `ResourceDef` (log bundle, stone blocks, iron ingot, firewood stack, hammer/axe tools, wheat sheaf, cabbage, berries, mushroom, haunch, fish). Add `icon: Texture2D` to `ResourceDef` and use icons in the HUD resource bar and info panels.
- Texture filtering for pixel art: project default `texture_filter` nearest.

## Out of scope
- Terrain, building, and settler art (0024–0026).

## Acceptance criteria
- [ ] Running the generator twice yields identical files (deterministic).
- [ ] Every good has a distinct, recognizable icon shown in the HUD.
- [ ] Style guide exists and later art tickets reference it.
- [ ] Headless run is free of script errors.
