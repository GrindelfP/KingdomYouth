# KingdomYouth

A Banished-like settlement builder. You never control your settlers directly. You place buildings, set how many settlers work in each profession, and keep the stockpile healthy, while the settlers look after their own hunger, rest, and warmth.

Balance growth against food, warmth, and shelter as the seasons change.

> **Status:** v0.2 ("Banished loop") is complete: MVP milestones M0–M5 and the v0.2 milestones M6–M10 are done. The balance is tuned but will keep changing; see [docs/balance.md](docs/balance.md).

## Features

- Top-down 2D tile-grid world with forests, lakes, and rock, drawn with generated pixel art and a different look in each season
- Settlers with needs (hunger, rest, warmth, health) who act on their own, age, form families in houses, have children and die of old age
- Buildings: house, forester's lodge, gatherer's hut, hunting cabin, fishing dock, quarry, mine, crop fields (4x4, 6x6, 8x8), woodcutter, blacksmith, stockpile, storage barn
- Physical storage: goods are hauled by settlers to storage with limited capacity
- Roads: dirt roads (free) and stone roads (1 stone per tile) speed settlers up and attract their paths; demolish buildings, sites, or roads to get room back (buildings return half their cost)
- Banished-style labor: laborers haul materials, builders construct, and you set profession counts
- Crop fields with a seasonal lifecycle: plow and plant in spring, grow in summer, harvest in autumn, frost in winter
- Seasons, a month/year calendar, and winter heating from each house's own firewood
- Households: houses keep their own food and firewood, and settlers fetch and eat from them
- Crafting: woodcutter (logs to firewood) and blacksmith (iron and logs to tools); tools wear out and speed up work
- Births, deaths, and a population that depends on housing and food
- HUD with resource bar, clock and game speed (pause, 1x, 2x, 5x), a compact category build menu, profession panel, info panel, and toasts
- Save and load to a JSON file; saves from older versions are rejected with a message

## Requirements

- [Godot 4.4.1](https://godotengine.org/download/archive/4.4.1-stable/)

## Running the game

Open the project in Godot 4.4.1 and press **Play**, or run it from the terminal:

```sh
godot --path .
```

## Controls

| Action | Control |
| --- | --- |
| Pan the camera | `W` `A` `S` `D` or arrow keys |
| Zoom | Mouse wheel |
| Select a settler, building, or construction site | Left-click |
| Cancel a construction site (refunds delivered materials) | Right-click it, or `Delete` with it selected |
| Professions panel | `P` or the **Professions** button |
| Open or close the build menu | `B` or a category tab at the bottom of the screen |
| Place a building | Pick it in the build menu, then left-click (`Tab` cycles buildings, `R` resizes fields) |
| Lay a road | Pick **Dirt road** or **Stone road** in the build menu, then drag with the left mouse button in a straight or L-shaped line; release to place |
| Demolish a building, site, or road | `X` or the **Demolish** button, then left-click it. `Esc` or right-click stops demolishing |
| Pause / resume | `Space` |
| Game speed | `1` (normal), `2` (fast), `3` (fastest), or the top bar buttons |
| Save / load | `F5` / `F9` |

The full guide to controls, buildings, and the first hour of play is in [docs/tutorial.md](docs/tutorial.md).

## Tests and tools

Headless checks (see [docs/balance.md](docs/balance.md) for what they print):

```sh
G=/Applications/Godot.app/Contents/MacOS/Godot
$G --headless --path . --fixed-fps 30 res://tools/soak/soak.tscn -- --mode=planned --years=3
$G --headless --path . res://tools/soak/roundtrip.tscn -- --phase=save
$G --headless --path . res://tools/soak/roundtrip.tscn -- --phase=load
```

Art is generated by `tools/art/generate_art.gd` (see [docs/art-style.md](docs/art-style.md)).
